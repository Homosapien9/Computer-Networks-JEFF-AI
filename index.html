Q10 What is a computer network? Mention any two advantages of networking.
Board 20202M
▼
Answer

Computer Network: An interconnection of two or more computing devices that can communicate and share resources (files, printers, internet) using a communication medium.

Network Hardware Devices — Board 2008–2025
Q11 What is a Modem? Where is it used?
Board 20081M
▼
Answer

Modem (Modulator-Demodulator) converts digital signals from a computer to analog signals for transmission over telephone/cable lines (modulation), and converts received analog signals back to digital (demodulation). It is used to connect computers to the Internet via ISP telephone or cable infrastructure.

Q12 Identify the following devices:
(i) An intelligent device that connects several nodes and redirects received information only to the intended node(s).
(ii) A device that regenerates (amplifies) the received signal and re-transmits it.

(i) Switch — uses MAC address table to send data only to the intended recipient device, not to all ports.

(ii) Repeater — receives a weakened signal, amplifies/regenerates it, and retransmits it to extend network range. Works at Physical Layer.

Q14 What is the function of a Router in a network?
Board 20171M
▼
Answer

A Router connects two or more different networks (e.g., LAN to Internet). It reads IP addresses and determines the best path (route) for data packets across networks. It operates at the Network Layer (Layer 3) of the OSI model.

Q15 Beauty Lines Fashion Inc. has a design unit and market unit 135 m apart. After connecting their LANs using Ethernet cable, they cannot share information due to signal loss. Which device should be installed?

▼
Answer

(iii) Repeater — Standard Ethernet cable (UTP) has a maximum segment length of ~100 m. At 135 m, the signal degrades. A Repeater regenerates the signal, allowing it to travel the extended distance without loss.

Q16 Mr. Kant Sen Gupta wants to prevent unauthorised access to/from his company's LAN. Name a system (software/hardware) he should install.
All India 20111M
▼
Answer

Firewall — A Firewall (hardware or software) monitors and filters incoming/outgoing network traffic based on security rules, preventing unauthorized access between the trusted internal network and external networks like the Internet.

Q17 Differentiate between a Repeater and a Gateway.
SQP 20232M
▼
Answer

Repeater: Receives a weakened signal and retransmits it at original strength to extend network range. Works at Physical Layer; does NOT filter or route traffic.

Gateway: Connects networks using different protocols, translating between incompatible protocols. Acts as an entry/exit point between two different networks. Works at all OSI layers.

Domain Name: income.in — the registered hostname of the web server.

Q29 What is DNS? Why is it needed?
Board 2022, SQP 20252MImp
▼
Answer

DNS (Domain Name System) translates human-readable domain names (e.g., www.google.com) into IP addresses (e.g., 142.250.195.46) that computers use to communicate.

Why needed: Every device on the internet uses a numerical IP address, which is hard for humans to remember. DNS acts as the Internet's phone book, allowing users to type easy names instead of numeric IP addresses.

Q30 Define the term bandwidth with respect to networks.
SQP 2023-242M
▼
Answer

Bandwidth is the maximum rate of data transfer over a given transmission medium, measured in bits per second (bps) or multiples (Kbps, Mbps, Gbps). It represents the capacity of the network channel — the higher the bandwidth, the more data can be transmitted per second.

Q31 HTTPS (HyperText Transfer Protocol Secure) uses _______ to encrypt data transmitted over the Internet. How is it different from HTTP?
SQP 2023-242M
▼
Answer

HTTPS uses SSL/TLS (Secure Socket Layer / Transport Layer Security) to encrypt data.

HTTPS vs HTTP: HTTPS encrypts all data between browser and server, protecting passwords and sensitive information from interception. HTTP transmits data as plain text — visible to any intermediary. HTTPS is indicated by a padlock icon in browsers.

  • IaaS (Infrastructure as a Service): Virtualized hardware — AWS EC2, Azure.

Q36 How is a Hacker different from a Cracker?
Board 20082M
▼
Answer

Hacker: Gains unauthorized access primarily out of intellectual curiosity or to expose vulnerabilities (often without malicious intent). "White hat" hackers help organizations improve security.

Cracker: Breaks into systems with malicious intent — to steal data, cause damage, or commit fraud. Always illegal and harmful.

Key difference: Intent. Hackers are curious explorers; crackers are malicious attackers.

Q38 What is phishing? How can a user protect himself from phishing attacks?
Board 2022, SQP 20242MImp

Answer

  • Verify sender's email address carefully
  • Check for HTTPS and padlock icon in URLs

Q39 What is meant by "Denial of Service" (DoS) with reference to Internet service?
Delhi 20142M
▼
Answer

Denial of Service (DoS): A type of cyber attack in which a machine or network resource is made unavailable to its intended users by overwhelming it with excessive requests/traffic, causing it to crash or become unresponsive. A DoS attack does not typically allow the attacker to access or modify information — it simply denies service to legitimate users. A DDoS (Distributed DoS) uses multiple systems to launch the attack simultaneously.

Q40 What is a Trojan Horse in computing?
Board 20181M
▼
Answer

A Trojan Horse is malicious software disguised as legitimate software (game, utility, or email attachment). When run, it secretly performs harmful actions such as stealing data, creating backdoors for hackers, or damaging the system — all without the user's knowledge.

HOTS — Application & Reasoning
H1 A school wants to connect its 5 computer labs spread across 3 buildings within its campus. Which network type (LAN/MAN/WAN) would you recommend? Justify.
HOTS2M
▼
Answer

LAN (Local Area Network) is recommended. All buildings are within the same school campus — a confined area (typically under 1 km). LAN is designed precisely for connecting devices within a limited area belonging to a single organization. MAN is city-level; WAN is country/global — neither applies here.

H2 If a network administrator has a choice between a Hub and a Switch for a company's LAN, which should he prefer and why?
HOTS2M
▼
Answer

The administrator should prefer a Switch.

  • A switch sends data only to the intended destination (using MAC addresses); a hub broadcasts to all — causing unnecessary congestion.
  • Switches reduce collisions and improve performance.
  • Switches support full-duplex; hubs are half-duplex.
  • Switches provide better security (data not exposed to all ports).
H3 You visit a website and notice the URL starts with "https://" instead of "http://". What does the 's' signify and why is it important?
HOTS2M
▼
Answer

The 's' stands for Secure. HTTPS uses SSL/TLS encryption to encrypt all data between browser and server, protecting passwords and financial data from interception (man-in-the-middle attacks). It also verifies the website's authenticity via digital certificates. Critical for banking, e-commerce, and login pages.

H4 Two people are video calling each other. Which protocol — TCP or UDP — is more suitable for this real-time communication? Give reasons.
HOTS2M
▼
Answer

UDP (User Datagram Protocol) is more suitable for video calls.

  • Speed over reliability: Video calls are real-time — TCP's retransmission of lost packets causes disruptive delays.
  • Low latency: UDP doesn't wait for acknowledgements, maintaining continuous low-latency flow.
  • Dropping occasional packets causes a brief glitch (acceptable). TCP's "wait and retransmit" causes noticeable freezes.

Zoom, Teams, and Skype use UDP (or RTP over UDP) for live media.

H5 Why is Optical Fibre preferred over Coaxial Cable for long-distance high-speed internet backbone communication?
HOTS2M
▼
Answer
  • Extremely high bandwidth: Optical fibre can carry terabits/sec; coaxial is limited.
  • No electromagnetic interference: Light pulses are unaffected by electrical noise.
  • Low signal attenuation: Signals travel far without weakening — fewer repeaters needed.
  • Security: Very difficult to tap without detection.
H6 Meena uses the same password for her bank account and social media. Her social media account is hacked. Explain what additional risk she faces and what she should do immediately.
HOTS2M
▼
Answer

Risk — Credential Stuffing: The hacker will try the same username/password on banking and other sites. Her bank account is at serious risk.

Immediate actions:

  • Immediately change passwords on ALL accounts, especially banking
  • Enable Two-Factor Authentication (2FA) everywhere
  • Use unique, strong passwords for each account (use a password manager)
  • Monitor bank transactions for suspicious activity
H7 A student installed free software from an unknown website. After a few days, the college server started sending spam emails to all contacts automatically. Identify the type of malware and explain how it worked.
HOTS3M
▼
Answer

Trojan Horse (with Bot/Spam functionality)

  • The software appeared legitimate but contained hidden malicious code.
  • When installed, it opened a backdoor giving remote control to an attacker.
  • The compromised server became a bot in a botnet, sending spam using the server's legitimate email credentials.

Prevention: Only download from trusted official sources; use antivirus; enable firewall.

Competency-Based Questions (CBQs) — New Pattern 2021–2025
C1 An IT-based firm is planning to set up a network for its branches. Suggest an ideal layout (topology) to connect the branches and justify your choice.
Board 2024Competency2M
▼
Answer

Star Topology is ideal for connecting branches.

Justification: In star topology, each branch connects to a central hub/switch. It is easy to add new branches, simple to troubleshoot, and failure of one branch does not affect others. The central hub provides centralized management and monitoring of all network traffic.

C2 Assertion (A): In Star topology, if the central switch fails, all communication in the network stops.
Reason (R): In Star topology, all devices are connected to a central switch/hub.
SQP/Board 2023Competency1M
▼
Answer

(A) Both Assertion (A) and Reason (R) are true, and Reason (R) is the correct explanation of Assertion (A).

Since all devices connect through the central switch, failure of that central device cuts off all inter-device communication. This is the correct explanation — it is the centralised architecture that makes the network vulnerable to a single point of failure.

C3 Assertion (A): A primary key must be unique and cannot have NULL values.
Reason (R): The primary key uniquely identifies each row in the table.
(Note: This is a DB question but also tests network of data.)
SQP 2025-26Competency1M
▼
Answer

(A) Both A and R are True and R is the correct explanation for A.

A primary key must uniquely identify every row, which is why it cannot have duplicate or NULL values — the reason directly explains the assertion.

C4 Which type of network (PAN, LAN, MAN, or WAN) will be formed while connecting the Hyderabad campus to Bengaluru Headquarters?
SQP 2025-26Competency1M
▼
Answer

WAN (Wide Area Network) — Hyderabad and Bengaluru are cities in different geographic locations, hundreds of kilometres apart. Any network connecting two offices across such distances constitutes a WAN. LAN is for same-campus (up to ~1 km); MAN is city-level; WAN is inter-city/country.

C5 A hub sends data to all devices in a network. A switch sends data to the specific device. Which one is better in a high-traffic office network and why? (Competency: Justify with reason.)
SQP 2025-26Competency1M
▼
Answer

Switch is better in a high-traffic office network.

Reason: A switch reads the destination MAC address of each packet and forwards it only to the correct port. This eliminates unnecessary traffic and collisions, significantly improving network efficiency, speed, and security in high-traffic environments.

C6 An organization's office is located in a hilly region where cable installation is not feasible. Suggest the most suitable and economical wireless medium to connect their remote office with reasonable high speed.
CBSE 2019 Case, 2013Competency1M
▼
Answer

Satellite Communication / Microwave (via satellite link) is most suitable for hilly terrain. It provides wide coverage regardless of geographical obstacles and supports reasonable data speeds. Radio Waves via repeater towers are an alternative for shorter inter-office distances in hilly areas.

C7 The modem at the sender's computer end acts as a ______. (Fill in the blank — Competency MCQ)
SQP 2023-24Competency1M
▼
Answer

Modulator — At the sending end, the modem modulates (converts) the digital data from the computer into analog signals suitable for transmission over telephone/cable lines. At the receiving end, it demodulates analog signals back to digital.

CBSE Board 2024 — Actual Question Q.33
CB2 Infotainment Ltd. is an event management company with prime office in Bengaluru. Opening new division in Chennai at 3 locations: Vajra, Trishula, and Sudershana.

Distances (in metres): Vajra–Trishula: 60m | Vajra–Sudershana: 70m | Trishula–Sudershana: 80m

(iii) Which fast and effective wired transmission medium should be used to connect the Bengaluru prime office with Chennai division?
(iv) Which network device will be used to connect digital devices within each location of Chennai division?
(v) Is a repeater required in the given cable layout? Why/Why not?

▼
Answer

(i) Cable Layout (Star or linear):

  Trishula ─(60m)─ Vajra ─(70m)─ Sudershana
OR
  Trishula─Vajra─Sudershana (all distances <100m, no repeater needed)

(ii) Server: Vajra — It has the maximum number of computers (120). Placing the server here minimizes network traffic and response time for the majority of users.

(v) Repeater required? No — The maximum distance between any two locations is 80 m (Trishula–Sudershana), which is within the standard Ethernet 100 m limit. No repeater is needed.

SQP 2025-26 — Verified Networking Questions
S1 A hub sends data to all devices in a network, while a switch sends data to the specific device. Which of the following statements is correct?
(A) A hub sends data to all devices in a network, while a switch sends data to the specific device.
(B) A hub sends data only to the devices it is connected to, while a switch sends data to all devices.
(C) A hub and switch function the same way and can be used interchangeably.
(D) A hub and switch are both wireless networking devices.
SQP 2025-26SQP1MMCQ
▼
Answer

(A) A hub sends data to all devices in a network, while a switch sends data to the specific device.

A hub broadcasts to all ports regardless of destination (collision domain). A switch uses MAC address tables to send data only to the intended recipient port.

S2 A modem is a device that helps connect your computer to the internet. It converts digital signals from your device into analog signals for transmission. What is a Gateway?
SQP 2025-26SQP2M
▼
Answer

Modem: Converts digital signals to analog (modulation) for transmission over phone/cable lines, and converts received analog back to digital (demodulation).

Gateway: A device that connects two different networks that use different protocols, enabling communication between them. It translates between incompatible network architectures and acts as the entry/exit point for a network. Example: Home router acting as gateway between home LAN and the Internet.
